# Glossaire DeFi — EN / FR

| English | Français | Définition courte |
|---|---|---|
| **Wallet** | Portefeuille | Logiciel ou appareil qui détient les clés permettant de signer ; l'application ne reçoit pas la clé privée. |
| **Self-custody** | Auto-conservation | L'utilisateur garde le contrôle de ses actifs et signe lui-même chaque transaction. |
| **Transaction** | Transaction | Message signé et exécuté par le réseau, avec des comptes, des instructions et des frais. |
| **Program / smart contract** | Programme / contrat intelligent | Code déployé sur Solana qui vérifie des règles et modifie des comptes. |
| **PDA (Program Derived Address)** | Adresse dérivée du programme | Adresse déterministe contrôlée par un programme, calculée à partir de seeds ; elle n'a pas de clé privée classique. |
| **IDL (Interface Definition Language)** | Langage de définition d'interface | Schéma généré par Anchor décrivant instructions, comptes, types et erreurs d'un programme. |
| **RPC** | Relais d'appel réseau | Service utilisé pour lire Solana et envoyer des transactions ; un RPC ne peut pas forger une signature valide. |
| **Oracle / price feed** | Oracle / flux de prix | Source externe de données, par exemple un prix ; fraîcheur, identité et intervalle de confiance doivent être vérifiés. |
| **Slippage** | Glissement de prix | Écart maximal accepté entre le prix attendu et le prix exécuté. |
| **Liquidity pool (LP)** | Pool de liquidité | Réserve de deux actifs utilisée par un protocole d'échange pour calculer et exécuter des swaps. |
| **AMM (Automated Market Maker)** | Teneur de marché automatisé | Modèle d'échange qui fixe les prix à partir des réserves d'un pool plutôt que d'un carnet centralisé. |
| **ATA (Associated Token Account)** | Compte de token associé | Compte SPL standard associé à un wallet et à une mint donnée. |
| **Token mint** | Mint / émission | Compte décrivant un actif SPL ; ce projet n'en crée pas pour son produit. |
| **CPI (Cross-Program Invocation)** | Appel inter-programmes | Appel d'un programme Solana vers un autre, soumis aux contrôles de comptes et de signataires. |
